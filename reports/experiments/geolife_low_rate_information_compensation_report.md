# GeoLife 60 秒低采样率信息补偿实验报告

## 1. 实验目标与边界

本轮实验只研究论文主线：**在 GeoLife 用户互斥协议下，提高 60 秒低采样率 GPS 交通方式识别性能**。

所有保留候选均遵守以下边界：

- 推理只使用当前 60 秒轨迹片段，最多 6 个观测点；
- 不使用用户 ID、同用户历史、未来轨迹或测试时自适应；
- 主指标为 Accuracy 和 Macro-F1；
- 模块选择只依据用户互斥验证集；
- 只有验证集 Accuracy 与 Macro-F1 均提高至少 0.3 个百分点，候选才进入测试。

## 2. 最终保留设计

最终保留 **稀疏多时距关系编码 + 观测丢点一致性训练**：

1. 在当前片段的 5–6 个 GPS 观测点之间构造全部有效点对；
2. 同时编码单点特征、点对端点、点对差分和相对时间跨度；
3. 训练时以 50% 概率额外遮掉一个内部观测点，首尾点始终保留；
4. 对完整稀疏视图和更稀疏视图同时进行分类监督；
5. 约束更稀疏视图与原稀疏视图的类别分布和表示保持一致；
6. 推理阶段不丢点、不增加输入，也不需要稠密轨迹。

这个模块直接针对低采样率的核心困难：观测点太少时，单个点缺失会显著改变速度、方向和点间运动关系。训练期再稀疏化让模型学习对观测不足更稳定的表示。

## 3. 主结果（seed 10086）

| 方法 | Test Accuracy | Test Macro-F1 | 相对上一阶段 Accuracy | 相对上一阶段 F1 |
|---|---:|---:|---:|---:|
| 原始 B0 双分支基线 | 71.5535% | 63.7346% | — | — |
| V2 三专家框架 | 72.4888% | 66.0042% | +0.9353 pp | +2.2696 pp |
| V53 无历史置信度融合 | 73.9528% | 68.3033% | +1.4640 pp | +2.2991 pp |
| **最终观测恢复模块（V74）** | **74.2172%** | **68.6126%** | **+0.2643 pp** | **+0.3092 pp** |

最终方案相对原始 B0 的累计提升：

- Accuracy：**+2.6637 个百分点**；
- Macro-F1：**+4.8780 个百分点**。

验证集上，V74 相对 V53 提高：

- Accuracy：+0.3507 个百分点；
- Macro-F1：+0.5268 个百分点。

冻结的融合权重为 V53 0.88、V74 稀疏关系专家 0.12；最佳 checkpoint 为 epoch 57。

## 4. 本轮候选与结论

| 候选 | 核心想法 | 冻结测试相对 V53 | 结论 |
|---|---|---:|---|
| V74 | 训练期额外丢一个内部点并保持预测一致 | **Acc +0.264 / F1 +0.309 pp** | 保留 |
| V75 | 注意力与分位数稳健池化 | Acc -0.224 / F1 -0.090 pp | 极值信息丢失，淘汰 |
| V76 | V53/V74 置信度堆叠 | 验证未过门槛 | 淘汰 |
| V77 | 遮蔽点对关系重建预训练 | 验证未过门槛 | 重建未转化为分类收益 |
| V79/V80 | 显式稀疏统计树专家及 train+val refit | 最好 Acc -0.529 / F1 -0.145 pp | 验证到测试域迁移失败 |
| V81/V82 | 强/弱 Group-DRO | 验证未过门槛 | 欠拟合，淘汰 |
| V83/V85 | 运动学/几何双关系分支及 refit | 最好 Acc -0.081 / F1 +0.126 pp | 不能同时提高两指标 |
| V84 | V53+V74+V83 三路融合 | Acc -0.305 / F1 -0.275 pp | 淘汰 |
| V88 | 三个初始化的 V74 等权平均 | Acc -0.610 / F1 -0.622 pp | 初始化不稳定，淘汰 |
| V89 | 5 秒稠密教师到 60 秒稀疏学生蒸馏 | Acc -0.366 / F1 -0.317 pp | 跨用户泛化失败，淘汰 |

## 5. 严格模块消融

在完全相同的关系编码器、数据、seed 和训练预算下，关闭额外丢点、丢点分类损失及一致性损失：

| 设置 | Test Accuracy | Test Macro-F1 |
|---|---:|---:|
| 关闭观测恢复训练 | 73.7292% | 68.0489% |
| 开启观测恢复训练 | **74.2172%** | **68.6126%** |

观测恢复训练的独立贡献为 **Accuracy +0.4880、Macro-F1 +0.5637 个百分点**。


## 6. 必须说明的实验有效性限制

V74 是当前主 seed 的探索性最好结果，但还不能直接作为论文最终结论：

1. 额外模型初始化 42 和 2026 没有达到同等验证门槛；
2. 等权多初始化集成在测试上下降，说明增益对初始化不够稳定；
3. 长期迭代过程中测试集已被多次查看，当前测试集不再是严格意义上的“未见测试集”。

因此，当前结果能证明模块方向有潜力，但不能诚实地宣称已经获得稳定、无偏的最终论文增益。

## 7. 推荐的下一步

不要继续在当前测试集上调结构或权重。下一步应：

1. 固定本报告中的 V74 代码、超参数和融合权重；
2. 从未参与本轮开发的用户中建立一个新的 sealed test split；
3. 在固定协议上运行至少 3 个训练种子；
4. 报告 Accuracy、Macro-F1 的均值、标准差和每类 F1；
5. 若新 sealed split 上仍稳定为正，再扩展 5/10/20/30 秒结果和消融实验。
