# GeoLife 60 秒交叉拟合类别融合（V10）

## 结论

V10 没有超过已有最好版本，因此不采用为主方法。

| 方法 | Test Accuracy | Test Macro-F1 |
|---|---:|---:|
| B0 | 71.5535% | 63.7346% |
| V2 三专家全局融合 | 72.4888% | **66.0042%** |
| V9 类别感知堆叠 | **72.5702%** | 64.9453% |
| V10 五折堆叠 | 72.5295% | 64.9136% |
| V10 类别融合 | 72.4481% | 64.8767% |

当前 Accuracy 最好仍是 V9，Macro-F1 最好仍是 V2。V10 不替换它们。

## 设计

V10 针对 V2 和 V9 分别占优的问题，使用两层低容量交叉拟合：

1. 三个冻结专家的概率作为 15 维输入；
2. 五折逻辑回归堆叠器不在完整验证集上重新拟合，而是保留五个折叠模型并在测试时平均；
3. 第二层只学习五个类别系数，在 V2 与交叉拟合堆叠器之间逐类别选择；
4. 第二层再次使用五折 OOF 评估，避免用拟合内指标冒充泛化指标；
5. 测试阶段不训练、不校准、不选择系数。

验证集最终选择的类别系数为 `[0, 1, 1, 1, 1]`：Walk 使用 V2，其余四类使用交叉拟合堆叠器。

## 验证与测试

| 方法 | Validation Accuracy | Validation Macro-F1 |
|---|---:|---:|
| V2 | 74.7370% | 67.1854% |
| 五折堆叠 OOF | **76.6868%** | **69.9168%** |
| V10 第二层嵌套 OOF | 76.4062% | 69.5759% |

验证集明显优于 V2，但测试集没有复现该优势，说明不同用户之间仍有显著分布偏移。继续围绕同一个测试集修改类别系数会构成测试集调参，因此本轮到此冻结。

## 复现命令

```bash
python -m scripts.evaluate_crossfit_class_blend select --rate 60
python -m scripts.evaluate_crossfit_class_blend test --rate 60
```

## 后续建议

如果目标是获得一个同时超过 V9 Accuracy 和 V2 Macro-F1 的可信模型，下一阶段需要把模型选择转移到新的开发证据上：优先用多个训练随机种子或从训练用户中建立第二个用户互斥开发折。不能继续根据当前 4,918 条测试样本的结果挑门控规则。
