# GeoLife 五采样率双专家共识实验

## 结论

本轮得到一个在五种采样间隔上均未退化的有效方案：保留原始双分支基线 B0，增加一个只读取运动统计特征的独立专家，并在用户互斥验证集上完成温度校准与概率融合权重选择。

五档独立测试的平均 Accuracy 从 74.05% 提升到 75.16%，平均 Macro-F1 从 68.17% 提升到 69.66%。平均提升分别为 1.11 和 1.49 个百分点。

## 方法

- 主专家：原始双分支基线 B0，同时使用轨迹坐标分支和运动特征分支。
- 辅助专家：单分支 Transformer，只使用速度、加速度等 4 维运动统计特征。
- 校准：分别在用户互斥验证集上选择温度，使负对数似然最小。
- 融合：`p = (1 - alpha) * p_B0 + alpha * p_feature`。
- 选权：`alpha` 在 `[0, 1]` 上以 `0.01` 为步长搜索，验证集 Accuracy 为主指标，Macro-F1 用于打破并列。
- 独立性：测试集不参与温度或融合权重选择。

该设计针对目前发现的核心问题：采样变稀疏时，原始坐标轨迹分支的信息量下降，而且用户互斥验证集与测试集的类别比例不同。单独训练复杂纠正头容易拟合验证集类别比例；双专家使用全局标量权重，不做类别专属修正，因而对类别比例变化更稳健。

## 实验设置

- 数据集：GeoLife 五档固定采样率视图。
- 采样间隔：5、10、20、30、60 秒。
- 划分：用户互斥 train/validation/test。
- 随机种子：10086。
- 最大训练轮次：200。
- Early stopping patience：40。
- 输入：`50%noise`，与既有五档基线相同。
- 指标：Accuracy 与 Macro-F1。

## 本轮排除的方案

- 低学习率继续微调 B0：独立测试退化。
- 类别专属 motorized correction：验证集提升但测试集因类别比例变化而明显退化。
- 三专家堆叠与逻辑回归 stacking：验证集过拟合，独立测试没有优于简单双专家共识。
- 复杂置信门控：没有超过简单的校准概率融合。

这些失败方案的临时代码和配置不提交，避免仓库继续产生多个难以维护的“版本”。

## 下一步建议

1. 先以本方案作为当前候选模块，不再继续堆复杂结构。
2. 用 3 个随机种子复核五档均值与标准差，并对配对预测做显著性检验。
3. 将 5 秒专家学习率降低后重跑，消除非有限训练这一实现风险。
4. 若多种子仍稳定，再考虑将两个专家联合蒸馏为一个模型，降低推理成本。

## 当前判断

本轮已达到“有提升效果”的停止条件：五种采样率的 Accuracy 和 Macro-F1 全部为正向，且 10、20、30 秒的 Accuracy 均提升超过 1 个百分点。但目前只有单随机种子，且属于双模型融合，仍不能直接宣称为论文最终结果。
