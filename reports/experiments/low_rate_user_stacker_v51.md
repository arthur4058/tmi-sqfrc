# 60 秒低采样率用户稳健堆叠实验（V51）

## 结论

V51 达到了本轮预设目标，并在两个随机种子上同时提高 Accuracy 和
Macro-F1。seed10086 的 Accuracy 首次超过 74%。

V51 不是继续增加大型深度分支，而是在现有低采样率专家之上加入一个
强正则、用户互斥验证的轻量堆叠层。它利用不同专家错误的互补性，并用
留一验证用户（leave-one-user-out）预测选择参数，降低对某一个验证用户的
过拟合。

## 固定实验设置

- 数据：GeoLife 用户互斥数据协议
- 任务：60 秒固定采样间隔、5 类交通方式识别
- 测试样本：4,918
- 指标：Accuracy、Macro-F1（越高越好）
- 主探索种子：10086
- 额外确认种子：42
- 选参阶段不读取测试标签

## 方法

输入堆叠层的五组概率为：

1. V2 三专家共识概率；
2. `cp000_u050` 短轨迹专家；
3. `cp100_u000` 类别均衡短轨迹专家；
4. 位置与绝对时间不变的统计运动专家；
5. V24 经类别边界校准得到的 V25 概率。

将五组概率取对数后拼接，训练多项 Logistic Regression。选择阶段按验证
用户留一交叉预测，并在堆叠预测与 V25 之间做保守融合。

最终冻结参数：

```text
C = 0.001
class_weight_power = 0.5
user_weight_power = 0.0
fusion_alpha = 0.5
```

## 本轮筛选摘要

- V30 BiGRU、V39 大核短序列网络：验证表现尚可，但测试用户迁移失败；
- V31/V32/V44/V48/V49：与现有专家错误高度重合，稳健融合权重为 0；
- V33/V34/V45：类别门控有效，V45 达到 73.8105% / 67.8739%；
- V35/V40：高容量门控在验证集明显过拟合；
- V37/V38：用户均衡与用户对抗训练没有改善；
- V50：成对分歧门控的留一用户结果低于 V45；
- V51：留一用户强正则堆叠首次越过 74% Accuracy，并在 seed42 重复提升。

## 复现命令

先生成并筛选两个短轨迹专家，再生成 V24/V25；随后运行：

```bash
python -m scripts.low_rate_user_stacker select --seed 10086
python -m scripts.low_rate_user_stacker test --seed 10086

# 使用 seed10086 冻结的超参数确认 seed42
python -m scripts.low_rate_user_stacker frozen --seed 42 --test-frozen
```

```bash
python -m unittest tests.test_low_rate_user_stacker
```
