# GeoLife 类别感知低采样率融合 V8 实验报告

## 最终结论

V8 没有同时超过当前最佳 V2，不能作为新的主方法。

V8 在 60 秒独立测试集上相对 B0 仍取得双指标提升，但与 V2 相比仅
Accuracy 增加 0.08 个百分点，Macro-F1 下降 1.06 个百分点。综合判断：
继续保留 V2 作为当前最佳低采样率方案，V8 作为有完整负结果记录的消融。

| 60 秒方法 | Accuracy | Macro-F1 | 相对 B0 Accuracy | 相对 B0 Macro-F1 |
|---|---:|---:|---:|---:|
| B0 双分支基线 | 71.5535% | 63.7346% | - | - |
| V2 三专家全局融合 | 72.4888% | 66.0042% | +0.9353 pp | +2.2696 pp |
| V8 类别感知融合 | 72.5702% | 64.9453% | +1.0167 pp | +1.2107 pp |

V8 相对 V2：Accuracy `+0.0813 pp`，Macro-F1 `-1.0589 pp`。

## 实验目标

此前 V2 使用 B0、4 特征专家和 7 特征运动专家的全局非负权重融合，在
60 秒档取得 `72.49% / 66.00%`。本轮尝试解决两个残余问题：

1. 60 秒窗口只有约 6 个观测点，高采样率和低采样率的内部表示差异大；
2. 单一全局权重不能针对 Walk、Bike、Bus、Car、Train 分别选择可靠专家。

## 固定实验协议

- 数据：GeoLife 五档数据中的固定 60 秒采样视图；
- 窗口：300 秒物理时间窗；
- 划分：训练、验证、测试用户互斥；
- 训练样本：62,786；
- 验证样本：7,129；
- 测试样本：4,918；
- 随机种子：10086；
- 输入设置：`50%noise`；
- 模型选择只使用用户互斥验证集；
- 独立测试在方案和参数冻结后执行一次。

## 尝试一：5 秒教师类别原型对齐

首先从冻结的 5 秒 B0 模型中提取 128 维类别原型，再用辅助损失约束
60 秒模型的融合表示靠近正确类别的 5 秒原型。

原始原型的类别间余弦相似度约为 `0.825--0.960`，公共成分很强。随着
辅助损失权重增加，Car 大量被预测成 Train：验证 Accuracy 从第 2 轮的
72.83% 降至第 9 轮的 62.38%，Macro-F1 从 62.60% 降至 48.40%。

随后测试去除原型公共成分、权重由 0.05 降至 0.01 的 V8.1。该版本仍然
发生相同的 Car/Train 坍缩，第 8 轮验证仅为 58.38% / 42.03%。因此提前
终止，且两个原型版本均未读取测试集。

结论：不同采样率下的隐藏空间并不天然同构，直接做跨采样率几何对齐会
产生负迁移。这条路线不并入最终代码。

## 尝试二：类别感知三专家融合

三个已训练专家全部冻结：

1. B0 双分支模型；
2. 4 特征专家；
3. 7 特征运动专家。

每个专家先使用验证集温度校准。V8 将三个专家的 5 类对数概率拼接为
15 维输入，用一个多项逻辑回归学习类别专属的融合关系。融合器只有
`5 x 15 + 5 = 80` 个参数，不增加深度模型训练，也不改变数据协议。

为减少验证用户过拟合，使用固定随机种子 10086 的五折分层交叉验证，
搜索：

- 正则参数 `C`: 0.003、0.01、0.03、0.1；
- 类别平衡指数：0、0.25、0.5。

选择准则为 OOF Accuracy 与 Macro-F1 等权，选中 `C=0.01`、类别平衡
指数 `0.25`。这只是轻度少数类校准，不是完全类别均衡。

## 验证结果

| 方法 | Accuracy | Macro-F1 |
|---|---:|---:|
| V2 全局融合 | 74.7370% | 67.1854% |
| V8 五折 OOF | 76.6868% | 69.9168% |
| V8 全验证集重拟合 | 76.6727% | 69.8597% |

V8 在五折 OOF 上相对 V2 验证结果提高约 `+1.95 pp Accuracy` 和
`+2.73 pp Macro-F1`，满足预先设定的测试门槛，因此冻结参数后执行一次
独立测试。

## 独立测试结果

| 方法 | Accuracy | Macro-F1 |
|---|---:|---:|
| B0 | 71.5535% | 63.7346% |
| V2 | 72.4888% | 66.0042% |
| V8 | 72.5702% | 64.9453% |

验证提升没有完整迁移到测试用户。V8 的类别专属融合在验证用户上学习了
更细的混淆修正，但这部分关系具有用户依赖性；V2 的三个全局权重反而有
更好的跨用户稳健性。

## 可复现命令

```bash
python -m scripts.evaluate_class_aware_stacker select --rate 60
```

参数冻结后独立测试：

```bash
python -m scripts.evaluate_class_aware_stacker test --rate 60
```

运行专项测试：

```bash
python -m unittest tests.test_class_aware_stacker
```

## 返回意见

1. 当前可正式采用的最好版本仍是 V2，而不是 V8。
2. V2 对 B0 的 60 秒提升为 `+0.94 pp Accuracy / +2.27 pp Macro-F1`，
   是目前最完整、最稳健的双指标改进。
3. 不建议继续在同一随机种子和同一测试集上调融合权重；这会形成测试集
   过拟合，不能成为可信论文结果。
4. 下一项高优先级工作应是补跑 V2 的 3--5 个随机种子，报告均值、标准差
   和每类别 F1，确认提升稳定性。
5. 若多种子仍成立，再与代表性低采样率方法做同协议比较；若不成立，应
   优先改进 7 特征运动专家的训练数据增强，而不是继续增加后处理复杂度。
